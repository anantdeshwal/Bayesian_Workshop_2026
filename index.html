Before the workshop

Please install everything in advance. Installing JAGS takes a few minutes.

  1. Install R and RStudio.
  2. Install JAGS. This is a separate program, not an R package.
  3. In RStudio, install the R packages: 
    install.packages(c("rjags", "MCMCvis"))
  4. Check that it works. This should print a version number with no error: 
    library(rjags)
Mac users: if library(rjags) cannot find JAGS, restart RStudio after installing JAGS and try again.
